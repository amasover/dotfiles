--attended (Story 5.8, the real VM's first bootstrap): everything a person
types comes first. One `sudo -v`, then a visudo-checked drop-in, mode 0440,
staged under a dotted name (sudo ignores it) and renamed into place; then
`yadm decrypt` for the archive passphrase; then the same bootstrap
`--check --unattended` and `--unattended` as a disposable run, and the
follow-ups --unattended skipped. A trap deletes the drop-in on success, on a
failed bootstrap, and on HUP/TERM/INT. The stub sudo runs its command
unprivileged, against a temp sudoers dir; the stub yadm logs every call,
answers `config yadm.gpg-program` with FAKE_GPG_PROGRAM (empty by default)
and fakes decrypt (FAKE_DECRYPT=fail fails it; success writes ~/.zshenv, as
the real archive does) unless REAL_YADM names the real one. TMPDIR is
$A/tmp, so a leftover gpg wrapper would show there.

named for an architecture (guest-vmware-x86_64 on daily-vm, and the arch-*
groups) add to that adapter; they do not count as a second one:

$ RUN_CLASS() { printf '[hostname_groups]\n"%s" = [\n' "$(uname -n)" > "$U/home/.config/metapac/config.toml"; for group in "${@:2}"; do printf '[arch]\npackages = [\n]\n' > "$U/home/.config/metapac/groups/$group.toml"; printf '  "%s",\n' "$group" >> "$U/home/.config/metapac/config.toml"; done; printf ']\n' >> "$U/home/.config/metapac/config.toml"; PATH="$U/bin:$PATH" HOME="$U/home" VM_HARNESS_GUEST_TOOLS_DIR="$U/tools" CUSTOM_PKGS_DIR="$U/pkgbuilds" FAKE_CLASS="$1" "$G" check --class "$1"; }; echo ready
ready
$ out=$(RUN_CLASS work-vm guest-vmware arch-aarch64 inbox-work-vm 2>&1); rc=$?; printf '%s\n' "$out" | grep -E '^--- class profile|FATAL'; echo "rc=$rc"
--- class profile: work-vm (guest-vmware, inbox-work-vm)
rc=0

--- class profile: daily-vm (guest-vmware, inbox-daily-vm)
rc=0
