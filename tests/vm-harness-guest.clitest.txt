--attended (Story 5.8, the real VM's first bootstrap): one `sudo -v`, then a
visudo-checked drop-in, mode 0440, staged under a dotted name (sudo ignores
it) and renamed into place. bootstrap runs without --unattended while the
drop-in exists, and a trap deletes it on success, on a failed bootstrap, and
on HUP/TERM/INT. The stub sudo runs its command unprivileged, against a temp
sudoers dir.

$ G=.local/bin/setup/vm-harness-guest; A=$(mktemp -d); mkdir -p "$A/bin" "$A/sudoers" "$A/home/.local/bin/setup"; printf '%s\n' '#!/bin/sh' 'printf sudo >> "$GUEST_LOG"' 'for a; do printf " <%s>" "$a" >> "$GUEST_LOG"; done' 'printf "\n" >> "$GUEST_LOG"' '[ "$1" = -v ] && exit 0' '[ "$1" = -n ] && shift' 'exec "$@"' > "$A/bin/sudo"; printf '%s\n' '#!/bin/sh' '[ "$1" = -cf ] && grep -q " ALL=(ALL) NOPASSWD: ALL$" "$2"' > "$A/bin/visudo"; printf '%s\n' '#!/bin/sh' 'exit 0' > "$A/bin/pacman"; printf '%s\n' '#!/bin/sh' '[ "$1" = rev-parse ] && exit 1' 'exit 0' > "$A/bin/yadm"; printf '%s\n' '#!/bin/sh' 'f=$VM_HARNESS_GUEST_SUDOERS_DIR/89-first-bootstrap' 'if [ -e "$f" ]; then printf "bootstrap <%s> drop-in %s: %s\n" "$*" "$(stat -c %a "$f")" "$(sed "s/^$(id -un) /USER /" "$f")"; else printf "bootstrap <%s> no drop-in\n" "$*"; fi' '[ -z "$1" ] || exit 0' 'case "${FAKE_BOOTSTRAP:-}" in fail) exit 7 ;; HUP | TERM | INT) kill -s "$FAKE_BOOTSTRAP" "$PPID" ;; esac' > "$A/home/.local/bin/setup/bootstrap"; chmod +x "$A/bin/"* "$A/home/.local/bin/setup/bootstrap"; RUN_ATT() { : > "$A/log"; PATH="$A/bin:$PATH" HOME="$A/home" GUEST_LOG="$A/log" VM_HARNESS_GUEST_SUDOERS_DIR="$A/sudoers" "$G" bootstrap --class work-vm --repo https://example.invalid/dotfiles.git "$@" 2>&1 | sed "s|$A|\$A|g" | grep -E '^(==> (sudo|Temporary)|bootstrap <|vm-harness-guest)'; echo "rc=${PIPESTATUS[0]} left: $(ls -A "$A/sudoers")"; }; echo ready

The hard gate validates class/adapter/inbox and exclusive NetworkManager
ownership before accepting package drift. Custom-PKGBUILD packages remain the
only unmanaged exception; metapac failures stay distinct.
