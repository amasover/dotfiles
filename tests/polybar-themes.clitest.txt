# polybar theme configs — color references must resolve (nord-colors bug).
# The nord-arrow capture shipped with its palette include commented out and
# pointing at a pre-themes-dir path; every ${colors.nordX} then fell back to
# polybar's defaults (black/white bars) once 5.5 made -c load-bearing. These
# checks are pure text over the tracked files: no polybar, no host state.
#
# Run from the repo root: clitest tests/polybar-themes.clitest.txt

$ TH=.config/polybar/themes; CLITMP=$(mktemp -d); echo ok
ok
$

both themes include the palette by its real (themes/nord) path, uncommented:

$ grep -c '^include-file = \$HOME/.config/polybar/themes/nord/colors$' $TH/nord-arrow/config.ini
1
$ grep -c '^include-file = \$HOME/.config/polybar/themes/nord/colors$' $TH/nord/config
1
$

nord's bars inherit bar/base — the section must exist (was lost in capture):

$ grep -c '^\[bar/base\]' $TH/nord/config
1
$

every ${colors.X} reference on a live (uncommented) line resolves to a
palette key or an inline [colors] key — nord-arrow:

$ sed -n 's/^\([a-zA-Z0-9-]*\)[ =].*/\1/p' $TH/nord/colors | sort -u > "$CLITMP/palette"
$ { cat "$CLITMP/palette"; sed -n '/^\[colors\]/,/^\[bar/{s/^\([a-zA-Z0-9-]*\)[[:space:]]*=.*/\1/p;}' $TH/nord-arrow/config.ini; } | sort -u > "$CLITMP/defined"
$ grep -v '^[[:space:]]*[;#]' $TH/nord-arrow/config.ini | grep -o '\${colors\.[a-zA-Z0-9_-]*}' | sed 's/^..colors\.//; s/}$//' | sort -u > "$CLITMP/refs"
$ comm -23 "$CLITMP/refs" "$CLITMP/defined"
$

...and nord:

$ { cat "$CLITMP/palette"; sed -n '/^\[colors\]/,/^\[bar/{s/^\([a-zA-Z0-9-]*\)[[:space:]]*=.*/\1/p;}' $TH/nord/config; } | sort -u > "$CLITMP/defined"
$ grep -v '^[[:space:]]*[;#]' $TH/nord/config | grep -o '\${colors\.[a-zA-Z0-9_-]*}' | sed 's/^..colors\.//; s/}$//' | sort -u > "$CLITMP/refs"
$ comm -23 "$CLITMP/refs" "$CLITMP/defined"
$

$ comm -23 "$CLITMP/refs" "$CLITMP/palette"
